# APB-Based SPI Master RTL Design

## Overview

This project implements an APB-based SPI Master using Verilog/SystemVerilog.

## Features

- APB interface
- SPI Master
- SPI control FSM
- Programmable baud-rate generation
- CPOL/CPHA configuration
- Configurable bit ordering
- SPI data transfer
- Interrupt request generation

## Tools Used

- Verilog HDL
- SystemVerilog
- QuestaSim
- VS Code
- Git
- GitHub

## Project Structure

- `rtl/` - RTL design files
- `tb/` - Testbench and verification files
- `docs/` - Project documentation and simulation results
